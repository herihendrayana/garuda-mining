# 👑 GARUDA MINING - Official Play-to-Earn Game

**GARUDA MINING** adalah permainan blockchain resmi yang dibangun di atas **InChain Mainnet**. Mainkan game ini, kumpulkan token **GRD**, dan jual ke marketplace untuk profit! 🚀

## 🎮 Fitur Utama

### ⛏️ Main Game
- **Tap to Earn**: Klik tombol untuk dapatkan koin GRD
- **Auto Tap**: Aktivkan mode otomatis untuk tap otomatis setiap 200ms
- **Speed Upgrade**: Tingkatkan earning per tap dengan membayar 800 GRD

### 💰 Token Management
- **Real Blockchain**: Semua transaksi tercatat di smart contract InChain
- **Kirim ke Wallet**: Pindahkan token GRD ke wallet manapun
- **Sell di Market**: Jual token GRD di marketplace untuk mendapatkan profit

### 🔐 Security & Legal

## 🚀 Quick Start

### Cara Main

1. **Buka Game**: Akses file `index.html` atau klik link live di bawah
2. **Install Metamask**: Jika belum punya, download dari [metamask.io](https://metamask.io/download/)
3. **Hubungkan Wallet**: Klik tombol "HUBUNGKAN METAMASK"
4. **Mulai Tap**: Tap tombol untuk dapatkan GRD
5. **Upgrade**: Jika punya 800 GRD, upgrade speed Anda
6. **Kirim Token**: Pindahkan GRD ke wallet Anda sendiri
7. **Sell di Market**: Jual di DEX untuk profit 📈

## 📊 Game Mechanics

### Earning Per Tap
- **Default**: 2 GRD per tap
- **After Upgrade**: +1 GRD per upgrade level
- **Max Speed**: Unlimited (semakin banyak upgrade, semakin cepat earning)

### Upgrade System
| Upgrade | Cost | Benefit |
|---------|------|---------|
| Speed Boost #1 | 800 GRD | +1 GRD per tap (3 total) |
| Speed Boost #2 | 800 GRD | +1 GRD per tap (4 total) |
| Speed Boost #N | 800 GRD | +1 GRD per tap (N+2 total) |

### Auto Tap Feature
- **Frequency**: 1 tap setiap 200ms (5 taps per detik)
- **Cost**: Toggle gratis, tidak perlu membayar
- **Bonus**: Bisa dikombinasikan dengan manual tap
